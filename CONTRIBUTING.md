# Contributing

Copyright is reserved; this repository is not offered under an open-source
licence. Open an issue to discuss proposed contributions and permissions before
submitting code. Do not contribute proprietary code or redistribute vendor
executables, icons, licence files, or business data.

For bug reports, include macOS, architecture, Portico version, Wine version,
Windows application version, and a minimal reproduction with synthetic data.
Inspect logs for private information before attaching them. Compatibility
reports should distinguish installer success, app launch, and complete workflows.

Changes to process management, persistence, paths, locking, or recovery need
regression tests. Run the test command in README and `scripts/build.sh`.
